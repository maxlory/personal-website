# Tokscale adaptation notice

This site's Tokscale Summary is adapted from Tokscale at commit
`246765b1f32c384c375601c4307477847355fbbf`:

https://github.com/junhoyeo/tokscale/tree/246765b1f32c384c375601c4307477847355fbbf

Original copyright (c) 2025 Junho Yeo. Tokscale is licensed under the MIT
License. The adaptation keeps the Summary, Contributions, accessible date
inspection, 2D/3D controls, Day Breakdown structure, Usage/Models tabs with
keyboard navigation, and the full Models table (Model/Tokens/Cost/Share,
cost-descending, provider color dots), maps colors to this site's Editorial
Instruments tokens, and replaces the original profile shell with a homepage
section and server-side data adapter.

The versioned snapshot and weekly updater are original static-export
integration code. They validate and retain only the public profile fields
needed by this presentation; upstream failure leaves the last successful
snapshot untouched.
